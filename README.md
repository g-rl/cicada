# cicada

a *JUP* GSC menu, created by [nyli2b](https://x.com/nyli2b) & [mjkzy](https://x.com/mjkzys)

- **you must own a license to the game in order to use cicada.**
- cicada is **only usable offline** by design and is not "cheats" or "hacks"

## download

to download and use cicada, check out the [Discord Server](https://discord.gg/5U7dChVgBe). this will have everything to install cicada.
